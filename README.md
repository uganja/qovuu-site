# qovuu.com

Coming-soon page for Qovuu. Plain HTML, no build step, hosted on GitHub Pages.

- `index.html` – the page (styles and script inline)
- `fonts/` – Unbounded and Figtree, self-hosted (SIL Open Font License)
- `CNAME` – tells GitHub Pages to serve this at qovuu.com

To change the copy, edit `index.html` and push to `main`; the live site updates in about a minute.
